托福阅读事实细节

Day3 细节题

1.事实信息 Factual Information

1.1 题目形式&出题频率

题目示例：According to the paragraph, which of the following is true of X?
出题频率：2-5 题，在 1-2 句话里就能找到答案

1.2 正确选项&错误选项

正确选项 文中有吗 和文中一致吗 是题目问的吗
正确选项 √ √ √
无中生有 × - -
偷换概念 √ × ×
答非所问 √ √ ×

偷换概念的三种套路：

  1. 过：范围扩大，程度加强：all, always, most, every, each, primarily, completely；范围缩小，程度减轻：only, never, least, any
  2. 混：混淆因果，混淆修饰语和被修饰语，混淆从属关系
  3. 反

2. 推断 Inference

2.1 题目形式&出题频率

题目示例：suggest, indicate, imply, can be inferred from the passage that
出题频率：1-2 题

2.2 正确选项&错误选项

推断题做法和事实信息题没有任何区别

2.3 推断不是脑补

  1. 对比取反
  2. 多次取同
  3. 虚拟语气

3.否定事实信息 Negative Factual Information

3.1 题目形式&出题频率

题目示例：According to the passage, which of the following is NOT true of X? The author’s description of X mentions all of the following EXCEPT …
出题频率：0-2 题

3.2 正确选项

无中生有，偷换概念，答非所有

3.3 错误选项

原文有，和原文一致，是题目问的

3.4 做题技巧

定位：原文的并列
简单题：不选的选项在原文中定位很近，顺序是一致的；选出的选项是无中生有
难题：不选的选项在原文定位不近，顺序打乱；选出的选项是偷换概念答非所问

4.指代 Reference

4.1 题目形式&出题频率

题目示例：The word X in the passage refers to
出题频率：X 是代词，0-2 个

4.2 正确选项

最接近的词最对的、语法正确、意思通顺的名词
最近的：就近原则；往前找
语法：单复数
意思：名词和前后的词搭配正确，逻辑合理

4.3 错误选项

远，语法，意思
