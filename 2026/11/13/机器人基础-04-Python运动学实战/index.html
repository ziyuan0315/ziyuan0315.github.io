概述

前面的内容主要从数学角度介绍了机器人位姿、坐标系变换、正运动学、逆运动学和雅可比矩阵。本篇进一步把这些概念落实到
Python 程序中，观察它们在实际计算链路中的组织方式。

本文按照从简单模型到真实机械臂模型的顺序展开：

  1. 使用齐次变换矩阵和 SpatialMath 表达三维位姿；
  2. 将相机坐标系中的目标位置转换到机器人基座坐标系；
  3. 使用几何公式和 SE3 变换链实现平面二连杆正运动学；
  4. 使用解析方法求解二连杆逆运动学，并处理多解、边界和无解情况；
  5. 从正运动学推导 Jacobian，建立关节微小运动与末端微小运动之间的关系；
  6. 通过行列式、条件数和奇异值观察奇异位形；
  7. 调用 Robotics Toolbox 中的 Franka Panda 模型，完成 FK、数值 IK 和
    Jacobian 计算。

配套源码包含完整脚本、测试案例和运行说明，正文只保留关键代码片段与数学关系。

2. 位姿与坐标变换：从六元组到 SE(3)

2.1 使用旋转矩阵表达姿态

三维刚体的位姿由位置（平移）和姿态（旋转）共同描述。对于姿态，一种常见的参数化方法是
Roll、Pitch、Yaw（RPY）。

本文采用以下组合约定：

R=Rz(ψ)Ry(θ)Rx(ϕ)R=R_z(\psi)R_y(\theta)R_x(\phi) R=Rz​(ψ)Ry​(θ)Rx​(ϕ)

其中：

  • ϕ\phiϕ：Roll，绕 xxx 轴的旋转角；
  • θ\thetaθ：Pitch，绕 yyy 轴的旋转角；
  • ψ\psiψ：Yaw，绕 zzz 轴的旋转角。

这里必须明确旋转顺序。对于列向量，矩阵乘积最右侧的矩阵先作用，因此上式对应先应用
RxR_xRx​，再应用 RyR_yRy​，最后应用 RzR_zRz​。

旋转矩阵可以表达完整的三维方向关系，但单独的旋转矩阵不包含平移信息。

2.2 齐次变换矩阵

为了在同一个矩阵中统一表达旋转和平移，引入齐次变换矩阵：

T=[Rt01]∈SE(3)T= \begin{bmatrix} R&t\\ 0&1 \end{bmatrix} \in SE(3) T=[R0​t1​]∈SE(3)

其中 R∈SO(3)R\in SO(3)R∈SO(3)，t∈R3t\in\mathbb{R}^3t∈R3。

对于同一个物理点，如果它在坐标系 {C}\{C\}{C} 下的齐次坐标为
Cpˉ{}^{C}\bar pCpˉ​，那么它在坐标系 {B}\{B\}{B} 下的坐标为：

Bpˉ=BTC Cpˉ{}^{B}\bar p={}^{B}T_C\,{}^{C}\bar p Bpˉ​=BTC​Cpˉ​

展开后，普通三维坐标满足：

Bp=BRC Cp+BtC{}^{B}p={}^{B}R_C\,{}^{C}p+{}^{B}t_C Bp=BRC​Cp+BtC​

因此，齐次变换矩阵不仅描述两个坐标系之间的位置和姿态关系，也可以将点坐标从一个坐标系转换到另一个坐标系。

SpatialMath 中的 SE3 类就是对三维刚体变换的封装。常用接口包括：

SE3.Trans() 创建平移变换，SE3.Rz() 创建绕 zzz
轴的旋转变换。SpatialMath 使用 * 表示 SE3 群上的变换组合，而不是 NumPy
数组的逐元素乘法。

需要注意，矩阵乘法顺序不能交换。以列向量为例，右侧变换先作用于点；不同的乘法顺序可能得到相同的旋转部分，却得到不同的平移结果。

2.3 相机坐标系到机器人基座坐标系

视觉抓取任务通常先由相机检测目标，再将目标转换到机器人基座坐标系，之后才能结合机器人运动学求解关节状态。

设相机坐标系为 {C}\{C\}{C}，机器人基座坐标系为 {B}\{B\}{B}，目标物体坐标系为
{O}\{O\}{O}。已知：

BTC{}^{B}T_C BTC​

以及：

CTO{}^{C}T_O CTO​

那么目标物体相对于基座的位姿为：

BTO=BTC CTO\boxed{ {}^{B}T_O={}^{B}T_C\,{}^{C}T_O } BTO​=BTC​CTO​​

变换链中的中间坐标系 {C}\{C\}{C}
首尾衔接，最终得到目标在基座坐标系下的表达。

实践中的一组示例参数为：

BtC=[0.300.6],ψ=30∘{}^{B}t_C= \begin{bmatrix} 0.3\\0\\0.6 \end{bmatrix}, \qquad \psi=30^\circ BtC​=​0.300.6​​,ψ=30∘

CpO=[0.5−0.10.2]{}^{C}p_O= \begin{bmatrix} 0.5\\-0.1\\0.2 \end{bmatrix} CpO​=​0.5−0.10.2​​

因此：

BpO=Rz(30∘) CpO+BtC{}^{B}p_O= R_z(30^\circ)\,{}^{C}p_O+{}^{B}t_C BpO​=Rz​(30∘)CpO​+BtC​

计算结果为：

需要注意，坐标轴的物理含义取决于采用的坐标系约定。相机光学坐标系、机器人基座坐标系和工具坐标系不一定采用相同的轴方向，不能脱离坐标定义直接把
xxx、yyy、zzz 解释成"前、右、上"。

3. 平面二连杆机械臂的正运动学

3.1 机构模型与变量定义

考虑一个在 XYXYXY 平面内运动的二连杆机械臂。两根连杆长度分别为
L1L_1L1​、L2L_2L2​，两个关节均为转动关节，旋转轴平行于 ZZZ 轴。

  • q1q_1q1​：第一根连杆相对于基座 XXX 轴的角度；
  • q2q_2q2​：第二根连杆相对于第一根连杆的相对角度。

因此，第二根连杆相对于基座的绝对方向角为：

q1+q2q_1+q_2 q1​+q2​

图 2｜平面二连杆机械臂的几何关系。第二关节角 q2q_2q2​
是相对角度，第二根连杆的绝对方向角为 q1+q2q_1+q_2q1​+q2​。

3.2 几何法推导 FK

第一根连杆末端，也就是肘部的位置为：

p1=[L1cos⁡q1L1sin⁡q1]p_1= \begin{bmatrix} L_1\cos q_1\\ L_1\sin q_1 \end{bmatrix} p1​=[L1​cosq1​L1​sinq1​​]

第二根连杆相对于基座的方向角为 q1+q2q_1+q_2q1​+q2​，因此第二段向量为：

p2=[L2cos⁡(q1+q2)L2sin⁡(q1+q2)]p_2= \begin{bmatrix} L_2\cos(q_1+q_2)\\ L_2\sin(q_1+q_2) \end{bmatrix} p2​=[L2​cos(q1​+q2​)L2​sin(q1​+q2​)​]

末端位置由两段向量相加得到：

p=p1+p2p=p_1+p_2 p=p1​+p2​

最终得到二连杆机械臂的正运动学方程：

x=L1cos⁡q1+L2cos⁡(q1+q2)y=L1sin⁡q1+L2sin⁡(q1+q2)\boxed{ \begin{aligned} x&=L_1\cos q_1+L_2\cos(q_1+q_2)\\ y&=L_1\sin q_1+L_2\sin(q_1+q_2) \end{aligned} } xy​=L1​cosq1​+L2​cos(q1​+q2​)=L1​sinq1​+L2​sin(q1​+q2​)​​

在 Python 中，这两条公式可以直接写成：

例如：

q1=30∘,q2=60∘,L1=L2=1q_1=30^\circ,\quad q_2=60^\circ,\quad L_1=L_2=1 q1​=30∘,q2​=60∘,L1​=L2​=1

则第二根连杆的绝对方向角为 90∘90^\circ90∘，末端位置为：

p=[cos⁡30∘+cos⁡90∘sin⁡30∘+sin⁡90∘]=[0.86601.5]p= \begin{bmatrix} \cos30^\circ+\cos90^\circ\\ \sin30^\circ+\sin90^\circ \end{bmatrix} = \begin{bmatrix} 0.8660\\1.5 \end{bmatrix} p=[cos30∘+cos90∘sin30∘+sin90∘​]=[0.86601.5​]

3.3 使用 SE3 变换链实现 FK

几何法适合简单平面机构，但当机械臂包含更多关节，或者需要计算末端完整三维姿态时，逐个推导末端位置公式会越来越繁琐。

可以将每个关节和连杆表示为一个刚体变换，再沿机械链依次组合：

对应的数学表达为：

T=Rz(q1)Tx(L1)Rz(q2)Tx(L2)T=R_z(q_1)T_x(L_1)R_z(q_2)T_x(L_2) T=Rz​(q1​)Tx​(L1​)Rz​(q2​)Tx​(L2​)

最终矩阵的平移部分与几何法得到的 x,yx,yx,y
完全一致，旋转部分则给出末端姿态：

θtool=q1+q2\theta_{\text{tool}}=q_1+q_2 θtool​=q1​+q2​

因此，几何法与 SE3
变换链并不是两套不同的运动学原理，而是同一个正运动学问题的两种表达方式。

4. 平面二连杆机械臂的逆运动学

4.1 工作空间与可达性判断

正运动学已知关节变量，计算末端位置；逆运动学则给定目标位置，反求能够实现该目标的关节变量。

设目标位置为：

pd=[xy]p_d= \begin{bmatrix} x\\y \end{bmatrix} pd​=[xy​]

目标点到基座原点的距离为：

r=x2+y2r=\sqrt{x^2+y^2} r=x2+y2​

当两根连杆完全伸展时，末端距离达到最大值
L1+L2L_1+L_2L1​+L2​；当两根连杆完全折叠时，末端与基座之间的最小距离为
∣L1−L2∣|L_1-L_2|∣L1​−L2​∣。

因此，目标点可达的几何条件为：

∣L1−L2∣≤r≤L1+L2\boxed{ |L_1-L_2|\leq r\leq L_1+L_2 } ∣L1​−L2​∣≤r≤L1​+L2​​

对于两根等长连杆，工作空间的内边界退化到基座原点。

4.2 使用余弦定理求解第二关节角

由二连杆正运动学：

x=L1cos⁡q1+L2cos⁡(q1+q2)y=L1sin⁡q1+L2sin⁡(q1+q2)\begin{aligned} x &= L_1\cos q_1+L_2\cos(q_1+q_2)\\ y &= L_1\sin q_1+L_2\sin(q_1+q_2) \end{aligned} xy​=L1​cosq1​+L2​cos(q1​+q2​)=L1​sinq1​+L2​sin(q1​+q2​)​

将两式平方后相加，可以得到：

x2+y2=L12+L22+2L1L2cos⁡q2x^2+y^2=L_1^2+L_2^2+2L_1L_2\cos q_2 x2+y2=L12​+L22​+2L1​L2​cosq2​

因此：

cos⁡q2=x2+y2−L12−L222L1L2\boxed{ \cos q_2= \frac{x^2+y^2-L_1^2-L_2^2}{2L_1L_2} } cosq2​=2L1​L2​x2+y2−L12​−L22​​​

进一步得到：

q2=±arccos⁡(cos⁡q2)\boxed{ q_2=\pm\arccos(\cos q_2) } q2​=±arccos(cosq2​)​

正、负两个分支对应不同的肘部构型。通常称为肘上解和肘下解，但具体标签取决于坐标定义和观察方向。更严格的说法是：它们是两个不同的解析解分支。

4.3 求解第一关节角

目标点相对于基座的方向角为：

γ=atan2⁡(y,x)\gamma=\operatorname{atan2}(y,x) γ=atan2(y,x)

由两根连杆构成的三角形可以得到第一关节角：

q1=atan2⁡(y,x)−atan2⁡(L2sin⁡q2, L1+L2cos⁡q2)\boxed{ q_1= \operatorname{atan2}(y,x) - \operatorname{atan2} \left( L_2\sin q_2,\, L_1+L_2\cos q_2 \right) } q1​=atan2(y,x)−atan2(L2​sinq2​,L1​+L2​cosq2​)​

这里使用 atan2(y, x) 而不是普通的 arctan⁡(y/x)\arctan(y/x)arctan(y/x)，因为 atan2
会同时考虑两个输入的符号，能够正确区分角度所在象限。

图
3｜相同末端目标对应的两组关节构型。两组解的末端位置相同，但肘部位置和机械臂形状不同。

例如，令：

L1=L2=1,(x,y)=(1,1)L_1=L_2=1,\qquad (x,y)=(1,1) L1​=L2​=1,(x,y)=(1,1)

得到：

cos⁡q2=0\cos q_2=0 cosq2​=0

因此：

q2=±90∘q_2=\pm90^\circ q2​=±90∘

对应两组解：

解分支 q1q_1q1​ q2q_2q2​

A 0∘0^\circ0∘ 90∘90^\circ90∘
B 90∘90^\circ90∘ −90∘-90^\circ−90∘

4.4 边界解、退化解与数值容差

解析公式并不意味着程序可以忽略数值问题。实际实现至少需要处理以下情况。

第一，反余弦的定义域。

理论上：

−1≤cos⁡q2≤1-1\leq\cos q_2\leq1 −1≤cosq2​≤1

但浮点运算可能使理论上等于 1 的结果变成 1.00000000011.00000000011.0000000001。如果直接调用
np.arccos()，就可能得到无效数值。

因此应先检查是否超出容差范围，再将容差内的数值裁剪到合法区间：

这里的裁剪只用于修正浮点舍入造成的微小越界，不能把真正不可达的目标强行变成可达目标。

第二，边界处的重复解。

当：

cos⁡q2=1\cos q_2=1 cosq2​=1

得到 q2=0q_2=0q2​=0。正、负两个分支实际上对应同一个完全伸展构型。

当：

cos⁡q2=−1\cos q_2=-1 cosq2​=−1

得到 q2=±πq_2=\pm\piq2​=±π。这两个角度在物理上也是同一个构型。

因此，程序需要对角度进行周期化处理，并过滤重复解。

第三，等长连杆的中心退化情况。

当 L1=L2L_1=L_2L1​=L2​ 且目标点恰好位于基座原点时：

r=0,q2=πr=0,\qquad q_2=\pi r=0,q2​=π

此时第一关节角 q1q_1q1​
可以任意变化，仍然能够使末端回到基座原点。因此，这个目标并不是只有一组
IK 解，而是存在无穷多组解。

配套代码在这一特殊情况下返回一组代表解，并在注释中明确说明其非唯一性。

第四，FK 回代验证。

IK 求解得到的关节角应重新送入 FK，检查：

FK(IK(pd))≈pdFK(IK(p_d))\approx p_d FK(IK(pd​))≈pd​

位置残差可以表示为：

ep=∥FK(q)−pd∥e_p=\|FK(q)-p_d\| ep​=∥FK(q)−pd​∥

这一步能够检查解析求解与程序实现是否一致，但仍然不能代替关节限位、碰撞和轨迹安全检查。

5. Jacobian：从关节运动到末端运动

5.1 Jacobian 的微分意义

FK 描述关节变量与末端位置之间的整体映射：

p=f(q)p=f(q) p=f(q)

对时间求导，根据链式法则：

p˙=∂f(q)∂qq˙\dot p= \frac{\partial f(q)}{\partial q}\dot q p˙​=∂q∂f(q)​q˙​

定义：

J(q)=∂f(q)∂qJ(q)=\frac{\partial f(q)}{\partial q} J(q)=∂q∂f(q)​

得到：

p˙=J(q)q˙\boxed{\dot p=J(q)\dot q} p˙​=J(q)q˙​​

对于当前构型附近的微小变化，可以写成：

Δp≈J(q)Δq\boxed{\Delta p\approx J(q)\Delta q} Δp≈J(q)Δq​

这里需要强调，Jacobian
描述的是局部线性关系。关节变化量较大时，不能将这一近似关系当作全局精确映射。

5.2 二连杆 Jacobian 的推导

二连杆正运动学为：

x=L1cos⁡q1+L2cos⁡(q1+q2)y=L1sin⁡q1+L2sin⁡(q1+q2)\begin{aligned} x &= L_1\cos q_1+L_2\cos(q_1+q_2)\\ y &= L_1\sin q_1+L_2\sin(q_1+q_2) \end{aligned} xy​=L1​cosq1​+L2​cos(q1​+q2​)=L1​sinq1​+L2​sin(q1​+q2​)​

分别对两个关节角求偏导：

J(q)=[∂x∂q1∂x∂q2∂y∂q1∂y∂q2]J(q)= \begin{bmatrix} \frac{\partial x}{\partial q_1}& \frac{\partial x}{\partial q_2}\\ \frac{\partial y}{\partial q_1}& \frac{\partial y}{\partial q_2} \end{bmatrix} J(q)=[∂q1​∂x​∂q1​∂y​​∂q2​∂x​∂q2​∂y​​]

最终得到：

J(q)=[−L1sin⁡q1−L2sin⁡(q1+q2)−L2sin⁡(q1+q2)L1cos⁡q1+L2cos⁡(q1+q2)L2cos⁡(q1+q2)]\boxed{ J(q)= \begin{bmatrix} -L_1\sin q_1-L_2\sin(q_1+q_2)&-L_2\sin(q_1+q_2)\\ L_1\cos q_1+L_2\cos(q_1+q_2)&L_2\cos(q_1+q_2) \end{bmatrix} } J(q)=[−L1​sinq1​−L2​sin(q1​+q2​)L1​cosq1​+L2​cos(q1​+q2​)​−L2​sin(q1​+q2​)L2​cos(q1​+q2​)​]​

矩阵的每一列描述对应关节对末端瞬时运动的贡献。

5.3 使用 Jacobian 求解关节微调量

如果已知期望末端微小位移 Δp\Delta pΔp，希望反求关节微小变化量，可以求解：

J(q)Δq=ΔpJ(q)\Delta q=\Delta p J(q)Δq=Δp

对于当前构型下可逆的二连杆 Jacobian：

Δq=J−1(q)Δp\Delta q=J^{-1}(q)\Delta p Δq=J−1(q)Δp

在 Python 中，推荐使用 np.linalg.solve()
求解线性方程组，而不是显式计算矩阵逆：

6. 奇异位形：为什么机器人会失去某些瞬时运动能力

6.1 通过行列式判断二连杆奇异性

二连杆 Jacobian 的行列式为：

det⁡(J)=L1L2sin⁡q2\boxed{\det(J)=L_1L_2\sin q_2} det(J)=L1​L2​sinq2​​

当：

q2=0或q2=πq_2=0\quad\text{或}\quad q_2=\pi q2​=0或q2​=π

有：

det⁡(J)=0\det(J)=0 det(J)=0

此时两根连杆共线，Jacobian 降秩，机械臂进入奇异位形。

图 4｜二连杆机械臂的外边界与内边界奇异构型。两种构型下 Jacobian
均降秩。

以完全伸直状态为例：

q1=0,q2=0q_1=0,\qquad q_2=0 q1​=0,q2​=0

此时：

J=[0021]J= \begin{bmatrix} 0&0\\ 2&1 \end{bmatrix} J=[02​01​]

因此：

[ΔxΔy]=[0021][Δq1Δq2]\begin{bmatrix} \Delta x\\ \Delta y \end{bmatrix} = \begin{bmatrix} 0&0\\ 2&1 \end{bmatrix} \begin{bmatrix} \Delta q_1\\ \Delta q_2 \end{bmatrix} [ΔxΔy​]=[02​01​][Δq1​Δq2​​]

无论关节如何产生微小变化，一阶近似下都有：

Δx=0\Delta x=0 Δx=0

这意味着末端失去了 xxx
方向的一阶瞬时运动能力。它并不代表末端永远不能改变 xxx
坐标，而是说明在当前构型附近，该方向上的一阶运动映射退化。

6.2 条件数与奇异值

行列式能够判断方阵是否奇异，但在接近奇异点时，还需要观察矩阵的数值条件。

对于 Jacobian，可以使用：

条件数越大，通常意味着线性求解对数值误差越敏感。最小奇异值越接近零，说明某个方向上的运动能力越弱。

在 L1=L2=1L_1=L_2=1L1​=L2​=1、q1=0q_1=0q1​=0 的情况下，测试结果如下：

     $q_2$   $\det(J)$  条件数

$90^\circ$      1.0000   2.618
$30^\circ$      0.5000   9.357
$10^\circ$      0.1736  28.584
 $1^\circ$      0.0175  286.472

随着机械臂接近完全伸直，Jacobian
的最小奇异值逐渐趋近于零，条件数迅速增大。

这也解释了为什么在奇异点附近直接使用普通逆矩阵可能得到异常大的关节运动量：当某个奇异值很小时，其倒数会变得很大。

6.3 阻尼最小二乘

为了改善奇异点附近的数值稳定性，可以使用阻尼最小二乘（Damped Least
Squares，DLS）：

Δq=JT(JJT+λ2I)−1Δp\boxed{ \Delta q= J^T(JJ^T+\lambda^2I)^{-1}\Delta p } Δq=JT(JJT+λ2I)−1Δp​

其中 λ\lambdaλ 是阻尼系数。

阻尼项能够限制小奇异值方向上的数值放大，但同时也会引入任务空间误差：

  • 阻尼较小：解更接近原始最小二乘结果，但在奇异点附近可能不稳定；
  • 阻尼较大：关节修正量受到更强抑制，但末端误差可能增大。

因此，阻尼系数不是越大越好。实际应用中需要结合当前构型、末端误差、关节运动范围和任务精度选择合适的参数。

7.5 冗余自由度与零空间运动

对于满行秩的 Panda Jacobian：

rank⁡(J)=6\operatorname{rank}(J)=6 rank(J)=6

根据秩-零度定理：

dim⁡(Null⁡(J))=7−6=1\dim(\operatorname{Null}(J))=7-6=1 dim(Null(J))=7−6=1

因此，存在非零关节速度向量 q˙\dot qq˙​，满足：

J(q)q˙=0J(q)\dot q=0 J(q)q˙​=0

这意味着在当前构型附近，机械臂可以改变自身关节状态，同时不产生末端的一阶瞬时运动。

使用 Moore-Penrose 伪逆，可以将关节速度分解为任务运动与零空间运动：

q˙=J+V+(I−J+J)z\boxed{ \dot q=J^+V+(I-J^+J)z } q˙​=J+V+(I−J+J)z​

其中：

  • J+VJ^+VJ+V：完成末端期望速度的关节运动；
  • I−J+JI-J^+JI−J+J：零空间投影矩阵；
  • zzz：次级任务希望实现的关节运动方向。

当末端需要保持静止时，V=0V=0V=0，则：

q˙=(I−J+J)z\dot q=(I-J^+J)z q˙​=(I−J+J)z

这为冗余机械臂提供了额外的运动调节能力，例如：

  • 在末端保持目标位姿的同时调整肘部位置；
  • 避开障碍物；
  • 远离关节限位；
  • 改善机械臂的可操作性。

这里描述的是当前构型附近的一阶瞬时运动关系。若要在一段时间内持续保持末端位姿，需要不断更新
Jacobian 和零空间方向，并结合碰撞检测、关节限位和轨迹规划进行约束。

9. 工程实现中的几个关键检查

从数学公式到可运行程序，中间还需要考虑数值稳定性和机器人本体约束。

检查项 需要确认的问题

坐标系 变换矩阵的参考系、目标系和乘法顺序是否一致
角度单位 程序内部是否统一使用弧度
IK 可达性 目标是否位于几何工作空间内
数值容差 反余弦输入是否存在浮点越界
多解选择 是否考虑当前关节状态和运动路径
FK 回代 IK 结果是否真正满足目标位姿
Jacobian 当前构型是否接近奇异位形
Panda 关节限位 求解结果是否处于允许范围
轨迹安全 运动过程中是否碰撞、超速或产生不连续变化

尤其需要区分三个判断：

  1. 几何可达： 目标是否满足机构的几何约束；
  2. 数值收敛： 求解器是否找到了满足误差阈值的数值解；
  3. 工程可执行：
    解是否满足关节限位、速度、加速度、碰撞和控制器约束。

这三个判断不能相互替代。

10. 总结

本次实践从最基础的齐次变换开始，逐步建立了完整的机器人运动学计算链路。

首先，使用 SE3
表达刚体位姿，并通过变换链完成不同坐标系之间的转换。随后使用平面二连杆分别实现
FK 和解析 IK，理解关节变量与末端位置之间的映射关系。

在此基础上，进一步从 FK 对关节变量求偏导，得到
Jacobian，描述关节运动与末端瞬时运动之间的局部关系。通过行列式、条件数和奇异值，可以识别机械臂运动能力退化的构型，并理解阻尼最小二乘的工程意义。

最后，将这些概念扩展到七自由度 Franka Panda。真实机械臂的数值 IK、6×7
Jacobian
和零空间运动，进一步说明了机器人运动学不仅要计算末端能否到达目标，还要考虑关节构型、运动路径和实际执行约束。

从视觉坐标变换到机械臂关节求解，核心始终是建立正确的空间关系，再通过运动学模型把任务目标转化为机器人可以执行的关节运动。
